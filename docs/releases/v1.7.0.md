# Faded Balancer DCTL v1.7.0

This release adds progressive two-point recovery for a faded or compressed RGB channel. A dark neutral sample establishes the first correction; the bright neutral sample is interpreted through that corrected result so the two stages concatenate inside one DCTL. Auto mode can identify a uniquely damaged channel, while explicit Red, Green, and Blue modes remain available when the shot needs manual direction.

The broader feature audit also produced several correctness and clarity fixes:

- Mixing shadow/highlight weights and donor luminance now affect both matrix and min/max mixing.
- Signed gamma, fade correction, and diagnostic log preview behave predictably with below-black and super-white values.
- Multiple channel replacements use the same input snapshot instead of cascading by control order.
- Preset-only mixing assistance can be disabled from the UI.
- User-facing labels and documentation distinguish legacy additive Lift behavior, scoped luminance preservation, broad tonal masks, donor-channel approximation, and the non-Cineon diagnostic preview.

Release validation now covers the complete numerical pipeline, progressive recovery, embedded presets, shell syntax, exact installer filenames, macOS/Metal host behavior, Windows/NVIDIA CUDA host behavior, and macOS payload identity. On the Windows CUDA host, the synthetic Auto result matched its clean reference pixel-for-pixel, and actual faded-footage renders confirmed that the bright step builds on the dark correction while leaving the two donor channels stationary.

The tested Windows configuration was Windows 11 Pro for Workstations, DaVinci Resolve Studio 20.3.2.9, an NVIDIA GeForce RTX 3090, and CUDA selected by Resolve. The numerical mirrors and source contracts also passed natively on Ubuntu 24.04, but this does not claim AMD/OpenCL or Linux Resolve runtime coverage; the available Linux host does not currently have DaVinci Resolve installed.

The Windows installer remains unsigned. The macOS package remains unsigned and not notarized. See `INSTALL.md` for the expected operating-system warnings and the installer-free manual option.
